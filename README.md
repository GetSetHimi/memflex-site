# memflex.dev — marketing site + docs for Memflex

Static Astro site for [memflex.dev](https://memflex.dev). Product repo (Python API, console, clients) lives at [GetSetHimi/memflex](https://github.com/GetSetHimi/memflex).

```bash
npm install
npm run dev      # local preview
npm run build    # static output in dist/
```

## Deploy (Vercel)

Import this repo in Vercel with defaults (Framework: Astro, Build: `astro build`, Output: `dist`). No environment variables needed — the site is fully static.
